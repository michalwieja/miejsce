This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Website for **Liceum Miejsce** (liceummiejsce.pl) — a private high school in Katowice, Poland. Built with Nuxt 2 (Vue 2), targeting static generation. Requires **Node 18**.

## Commands

```bash
npm run dev        # dev server on port 8000
npm run generate   # static build → dist/
npm run lint       # ESLint check
npm run lintfix    # ESLint auto-fix
```

Deploy by running `npm run generate` and serving the `dist/` folder.

## Environment

Copy `.env.exmaple` to `.env` and fill in:
- `GRAPHCMS_ENDPOINT` — GraphQL CMS endpoint (injected as `$graphcms` via `plugins/graphcms.js`)
- `BEARER` — GraphCMS bearer token
- `MAPS_API_KEY` — Google Maps API key (used in `plugins/vue2-google-maps.js`)

## Architecture

**Single-page layout** — `pages/index.vue` assembles all sections in order: Hero → Szkola → StandOut → Ludzie → Zajecia → Faq → RekrutacjaKtw → Kontakt. The layout (`layouts/default.vue`) wraps every page with `<Header>` and `<Footer>`.

**Sections vs Pages** — reusable page-section components live in `sections/`, while full routed pages live in `pages/`. Both are used as components inside `pages/index.vue`.

**Config-driven content** — all editable copy (FAQ items, class descriptions, people, expectations) lives in `config/*.js` files as exported arrays/objects. Update content there, not in Vue templates.

**Gallery** — `galleryConfig.json` is auto-generated by `galleryConfigCreator.js` (reads filenames from `static/gallery/`). Re-run `node galleryConfigCreator.js` after adding images.

**Styling** — SCSS with BEM, global variables in `assets/scss/variables.scss`, entry point `assets/scss/index.scss`. Component-scoped styles are written inline in `.vue` files.

**Plugins:**
- `plugins/vue2-google-maps.js` — registers Google Maps (SSR-enabled)
- `plugins/aos.js` — AOS scroll animations (client-side only)
- `plugins/graphcms.js` — injects `$graphcms` GraphQL client (server-side)
